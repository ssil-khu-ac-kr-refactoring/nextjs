# SSIL 홈페이지 · SPIS GUI 사용 설명서 (초안)

> 연구실 구성원용 사용 안내입니다. 관리자 기능은 로그인(`/login`) 후 사용합니다.

---

## 1부. 홈페이지 관리 (Admin CMS)

관리자 로그인 후 상단 `/admin` 으로 이동하면 좌측에 관리 메뉴가 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| **Home** | 메인 화면 문구(히어로/소개), 슬라이더 이미지 관리 |
| **About** | 소개 페이지 내용 편집 (리치 에디터) |
| **Research** | 연구 항목 추가/수정 — 제목·기간·상태(진행/완료)·대표이미지·본문 |
| **Publications** | 논문 목록 관리 |
| **News** | 소식 등록 (제목·날짜·이미지·본문) |
| **People** | 구성원 관리 (사진·역할·소개) |
| **Board** | 게시판 탭/글 관리 |
| **Contact** | 문의 내용 확인 |
| **Outcomes** | 연구 산출물 항목 관리 (아래 2부 참고) |

공통 사용법:
1. 목록 화면에서 **Add / + 버튼** → 새 항목 작성
2. 항목의 **Edit** → 수정, **Delete** → 삭제
3. **Published** 토글로 공개/비공개 전환 (비공개면 사이트에 안 보임)
4. **Order** 숫자가 작을수록 목록 위쪽에 표시
5. 이미지는 업로드 버튼으로 첨부 (서버에 저장됨)

## 2부. Outcomes / SPIS GUI (위성 표면 대전 시각화)

### 2.1 보기 (일반 사용자)

상단 메뉴 **Outcomes** → 좌측 목록에서 **Satellite Surface Charging** 선택.

- **기본 화면은 2D 세계지도**입니다. 상단/하단 축은 **LT(지방시)**, 좌측 축은 **위도**(30° 간격 고정 눈금).
- 지도 위 색상 = 평균 전위(AvPot). 범례: 초록(낮음)–노랑(중간)–빨강(높음, 절대값 기준 구간).
- 데이터는 **위도 2° × LT 1시간** 해상도로 표시되며, 셀에 마우스를 올리면 위도 범위·LT·전위값이 뜹니다.
- 지도의 어두운 영역은 **실시간 밤 반구**(태양 위치 기준)이고, 데이터 위치는 LT를 현재 시각 기준 경도로 변환(`lon = (LT − UTC) × 15°`)해 배치되므로 시간이 지나면 함께 이동합니다.
- **3D Globe** 버튼: 지구본 보기. `오로라 표시`를 켜면 NOAA **OVATION** 실시간 오로라 예보(5분 갱신)가 표시됩니다.
- 좌측 패널의 **재질 / 저항 / Solar / Kp** 등 드롭다운으로 조건을 선택합니다. 드롭다운은 **업로드된 데이터에 실제로 존재하는 값**으로 자동 구성됩니다.
- DB에 데이터가 없으면 같은 형식의 **데모 데이터**가 자동 표시됩니다 (실데이터 업로드 시 자동 대체).

### 2.2 데이터 업로드 (관리자)

`/admin/spis` (Admin → Outcomes → "위성 대전 데이터 업로드" 버튼)

1. **파일 형식**: `.csv` 또는 `.xlsx` (한셀 내보내기 호환, 시트명에 "all" 포함 시 해당 시트 사용)
2. **컬럼 구조** (DB structure 예시 그대로 인식):

```
cond_Solar, Kp, lat_center, ltime_center, e_n, e_T, i_n, i_T,
node, node0Material, node2Material, resistance, type, Potential
```

- 필수: `node0Material`, `Potential`, 그리고 `ltime_center`(또는 DN)
- `lat_center`(위도 중심)·`ltime_center`(LT 중심)가 있으면 지도에 위치 기반으로 표시
- `Potential` 이 빈 행은 자동으로 건너뜀
- 대소문자/공백/괄호/`_` 차이는 자동 흡수 (예: `Lat_Center` ↔ `lat_center`)
3. **새로운 열을 추가해도 됩니다** — 정해진 컬럼이 아니어도 자동 저장되고, 화면 좌측에 해당 이름의 필터 드롭다운이 자동 생성됩니다. (자세한 규칙: `docs/PARAMS.md`)
4. 업로드하면 **기존 데이터 전체가 새 파일로 교체**됩니다.
5. 업로드 후 Outcomes 화면을 새로고침하면 즉시 반영.

### 2.3 Outcomes 항목 관리 (관리자)

`/admin/outcome` — 산출물 항목(제목/요약/본문/이미지) 추가·수정·삭제, 게시 토글, 순서 지정.
- `Satellite Surface Charging` 항목은 시각화 전용(삭제 보호)이며 기본적으로 목록 하단에 위치합니다.
